# v1.4.0

The default web model policy now allows GPT-6 and GPT-5.6 Sol, and GPT-5.5 until October 14, 2026 at 00:00 UTC. Instant and Thinking variants in those families are included. Unsupported models are rejected before generation; the official-compatible models client lists only allowed backend entries. Raw discovery still exposes the full catalog. Set `IgnoreModelRestrictions = true` in runtime/native/proxy options, or call `ChatGPTWeb.Initialize(authenticationString, ignoreModelRestrictions: true)`, to try other backend slugs. Availability and account permissions still apply.

The new daily GitHub monitor compares UI fingerprints, API structure and model catalog with a committed baseline, then checks the real .NET 8 example using a fresh two-turn temporary conversation for each available allowed family. It verifies ordinary completion, SSE and remembered context. Linux CI uses normal Chromium on an invisible virtual display with automatic software-rendering fallback. It creates or updates one `[CHANGE]` issue and escalates it to `[CRITICAL]` when all attempted models fail or the SDK cannot use the API. Missing/expired authentication, access challenges and quota limits are blocked checks. Configure the private `CHATGPT_WEB_MONITOR_AUTH` repository secret with the extension's exported string. Monitor artifacts and issues contain no credentials or model output.

Tests, Build and Release remain separate workflow files. Tests calls the reusable Build workflow only after its full four-platform test matrix succeeds. Release reads tested-commit versions and notes as data, verifies provenance and the exact five build artifacts, accepts only the twelve required archives, computes checksums and uploads a draft before publishing. Its write-permission job has no checkout and executes no downloaded code. Exact immutable reruns are preserved and version tags never move.

Dependabot covers NuGet and Actions dependencies. SECURITY.md describes supported versions, private reporting and credential boundaries. README sources have moved to docs/REFERENCES.md; its original Notice area is preserved. Existing scoped MCP, project/temporary conversations, image/file operations and SSE support remain available.

Complete bundles include SDK DLLs, the proxy, dependencies, a .NET 8 example and pinned Chromium for Windows x64, Linux x64 and Intel/Apple Silicon macOS. The Firefox XPI remains unsigned; permanent installation in normal Firefox requires Mozilla signing. BrowserOnly remains reserved.
