# Reference review

All 13 additional repositories were cloned locally with their source and license files and reviewed on 2026-10-03. These are reference snapshots; an older client does not establish the current ChatGPT protocol. No source from these additional repositories was copied into the SDK. The conversation transport, stream parser, browser lifecycle, authentication extension and captured-operation mappings are implemented in this repository.

The original [Simatwa/WebChatGPT](https://github.com/Simatwa/WebChatGPT) is an older protocol reference. The supplied HAR provides the observed modern request shapes, project/temporary flags, file upload sequence and stream variants. [HAR_COVERAGE.md](HAR_COVERAGE.md) records those mappings without private values.

The replacement's public types come from the separately licensed, vendored [official OpenAI .NET SDK](https://github.com/openai/openai-dotnet), pinned to 2.14.0; its license is retained. The [official OpenAPI repository](https://github.com/openai/openai-openapi) is the source for the separate 353-operation REST catalog. This does not imply those platform endpoints are available on ChatGPT web.

Browser implementation uses Chromium's [unified headless mode](https://developer.chrome.com/docs/automation-and-testing/headless), the browser-level [SystemInfo DevTools domain](https://chromedevtools.github.io/devtools-protocol/tot/SystemInfo/), and the browser pinned by [Microsoft.Playwright](https://playwright.dev/dotnet/docs/browsers). Hardware availability is observed through Chromium's compositing status; software mode disables GPU rendering/compositing. Browser bundles retain their driver, Node and Chromium license notices.
